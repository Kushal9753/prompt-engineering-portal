# Prompt Engineering Learning Portal

A modern educational web portal to learn Prompt Engineering concepts, techniques, and real-world examples.

## 🚀 Features

- Prompt Engineering basics
- Prompt techniques (Zero-shot, Few-shot, Chain-of-thought)
- Practical prompt examples
- AI learning resources
- Dark mode / Light mode
- Responsive UI

## 🛠 Tech Stack

- React (Vite)
- TailwindCSS
- React Router
